# 欢迎来到我的博客

你好！这是我的个人博客网站。

## 关于这个博客

这个博客使用纯原生 HTML、CSS 和 JavaScript 构建，没有任何外部依赖。所有文章都使用 Markdown 格式编写，通过内置的解析器渲染成网页。

### 主要特点

- **简约设计**：左侧个人信息，右侧文章列表
- **Markdown 支持**：所有文章都用 Markdown 编写
- **研究区**：类似笔记软件的项目和文件夹组织方式
- **无外部依赖**：不引用任何外部网络资源

## 博客规划

我计划在这里分享：

1. 技术文章 - 编程学习心得、项目经验
2. 生活随笔 - 日常思考和感悟
3. 研究项目 - 各种感兴趣的主题研究

感谢你的访问！
