彩蛋文章？？？一个 HTML 文章页面示例

这是一篇用于测试博客文章排版系统的示例文章。 本页面故意使用大量不同的 HTML 语义元素， 用来检查 article-content 的 CSS 是否能够覆盖常见文章内容。

一、为什么使用语义化 HTML

Markdown 很方便，但 HTML 本身就是一种非常完整的文档描述语言。 如果文章正文统一放在 <article class="article-content"> 中，那么正文内部就不需要大量额外的 class。

例如我们只需要写 <h2>、 <p>、 <ul> 等标签，CSS 就可以自动完成排版。

五、引用

文档的结构应该服务于内容，而不是让内容迁就视觉样式。

当 HTML 元素已经能够准确表达内容含义时， 通常没有必要再额外添加 class。

六、图片与插图

图片可以直接使用 img 标签，并由 CSS 自动限制最大宽度。

二十、综合示例

到这里，一篇普通文章已经可以覆盖绝大多数内容类型。 例如我们可以先提出一个问题：

为什么一个静态博客仍然需要复杂的前端系统？

答案并不一定复杂。 如果文章本身就是结构良好的 HTML， 那么网站只需要负责提供统一的布局与样式即可。

因此，本系统的核心原则可以概括为： 内容负责语义，CSS 负责表现。
