示例文章：语义化 HTML 写作

无需 Markdown 转换，直接编写 HTML

欢迎来到示例文章！这篇文章展示了如何使用预定义的 CSS 类来快速编写格式优美的 HTML 文章。

传统的 HTML 写作需要记忆大量样式，而 Markdown 虽然简洁但需要转换步骤。我们的方案结合了两者的优点：

  • 保持 HTML 的原生结构，有利于 SEO 优化
  • 使用简洁的类名，写作体验接近 Markdown
  • 无需构建工具，保存即可预览
  • 每篇文章都是独立 HTML 文件，可被搜索引擎直接抓取

代码示例

在技术文章中，代码展示是必不可少的。你可以使用行内代码 console.log('Hello') 或者代码块：

// JavaScript 示例
function greet(name) {
    return `Hello, ${name}!`;
}

console.log(greet('World'));
提示：复制 template.html 文件，修改标题和内容，然后在 data/articles.json 中添加记录即可完成新文章发布。

总结

通过这套语义化的 CSS 类系统，你可以专注于内容创作，而不必担心样式问题。每篇文章都是独立的 HTML 文件，可以直接被搜索引擎索引，实现最佳的 SEO 效果。
